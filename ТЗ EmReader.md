# Техническое задание (ТЗ): Офлайн-читалка «EmeraldReader»

## 1. Общие требования и стек технологий
*   **Тип приложения:** Кроссплатформенное мобильное offline-приложение.
*   **Платформы:** Android 6.0+ и iOS 12.0+.
*   **Стек технологий:** Фреймворк Flutter (язык Dart), Flutter SDK. Среда разработки: VS Code (допускается Android Studio при необходимости).
*   **Инфраструктура:** Git/GitHub для контроля версий. Для сборки iOS-версии без локального Mac использовать облачный CI/CD (Codemagic или GitHub Actions).
*   **Размер приложения:** Строго оптимизировано. Итоговый размер установочного файла не должен превышать 35-40 МБ.
*   **Дизайн:** Стильное современное оформление в изумрудно-синих (изумруд `#0f5a5e`, синий `#081944`) контрастных цветах. Цвет `#654708` использовать для акцентов (кнопки, ссылки). Плавные, оптимизированные анимации в интерфейсе (60 FPS).

## 2. Политика безопасности и приватности (Offline First)
Приложение должно быть максимально безопасным и независимым:
*   **Защита кода:** Использовать обфускацию (ProGuard / R8 для Android, стандартная обфускация Flutter для iOS) для затруднения реверс-инжиниринга.
*   **Защита данных:** Строго запрещено логировать (выводить в `Logcat` / консоль разработчика) тексты из пользовательских файлов, чтобы исключить утечку данных.
*   **Телеметрия:** Никакие метрики или краш-репорты не отправляются без активного тумблера в настройках «Разрешить отправку отчетов об ошибках».
*   **Автономность и обновления:** Приложение полностью автономно. Проверка обновлений (запрос к `version.json` через GitHub API) происходит в фоне только при наличии активного интернет-соединения в момент запуска. Пользовательские данные при этом не передаются.

## 3. Работа с файловой системой
*   **Поддерживаемые форматы:** `docx` (или `doc`), `pdf`, `txt`, `epub`, `fb2`, `md`.
*   **Доступ к файлам:** При первом запуске приложение запрашивает доступ к основной папке с книгами (например, «Загрузки») через системный **Storage Access Framework (Android)** или **Document Picker / Files App (iOS)**. После получения URI-разрешения приложение автоматически сканирует эту папку и её подпапки при каждом запуске.
*   **Оптимизация чтения:** Для минимизации веса приложения рендеринг PDF должен осуществляться нативными средствами ОС (Native PDF rendering API). Форматы DOCX, FB2, EPUB парсятся легковесными Dart-библиотеками (извлечение текста + базовое форматирование) без интеграции тяжелых C++ движков.
*   **Сортировка и поиск:** Поиск по названию или ключевым словам. Сортировка: по дате добавления/изменения, по алфавиту, по размеру. Фильтрация по типу формата.

## 4. Навигация и структура экранов
Снизу экрана расположена панель (Bottom Navigation Bar) с 4 вкладками: «Главная», «Читалка», «Недавнее» и «Инфо». Навигация по приложению сопровождается плавными анимациями.

### 4.1. Вкладка «Главная»
Разделена на три визуальных блока:
1.  **«Все файлы»:** Сетка из типов файлов: docx (doc), pdf, txt, epub, fb2, md - и ВСЁ! Внутри каждой иконки встроен счетчик количества файлов данного типа. При нажатии открывается список файлов только этого формата. Список файлов можно сортировать: по дате добавления, по дате изменения, по алфавиту (Аа-Яя), по размеру файла.
2.  **«Быстрый доступ»:** Список добавленных пользователем файлов, отображающийся в несколько рядов (адаптируемых по размеру в зависимости от диаметра/размера экрана). Справа от названия раздела — иконка «+» для ручного добавления файлов в этот список (файлы тут тоже можно сортировать по типу). *Примечание:* Открытый файл можно добавить в «быстрый доступ» прямо находясь внутри читалки.
3.  **«Управление файлами»:** Три кнопки-иконки:
    *   **«Редактировать текст»:** Открывает модальное окно со списком всех файлов (с возможностью сортировки по типу файла). После выбора открывается красивый, но простой текстовый редактор. Можно редактировать любой поддерживаемый тип файла с сохранением исходного форматирования. Функции: изменять текст/форматирование, «Сохранить» (по умолчанию — в папку Загрузки), «Сохранить как», удалить файл, вернуться к списку файлов.
    *   **«Список заметок»:** Единая база всех заметок (расширение `.md`). Отображает: название заметки, текст и исходный файл. Если исходная книга удалена, заметка остается. Внутри заметки есть панель инструментов: выделение текста (полужирный), зачёркивание, курсив, заголовок, нумерованный и маркированный списки. Заметки можно: сортировать по типу исходного файла, удалить (помещаются в общую корзину приложения), а также импортировать/экспортировать в один единственный файл.
    *   **«Корзина»:** Экран удаленных файлов (можно сортировать только по типу файла). 
        * *Логика работы:* При удалении файл берется из оригинальной папки («Загрузки») и физически перемещается во внутреннюю скрытую кэш-директорию приложения (`.TrashReader`). Для пользователя он исчезает из проводника.
        * При нажатии «Восстановить» в корзине — файл перемещается обратно в «Загрузки».
        * При удалении файла показывается модальное окно: «Удалить файл?» с флажком «Удалить, минуя корзину» (если включен, файл стирается командой delete() навсегда без перемещения в корзину). Система запоминает выбор этого флажка по умолчанию.
        * В правом верхнем углу корзины кнопка «Очистить всё» -> открывает окно «Подтвердить удаление?». При подтверждении файлы навсегда стираются из памяти. 
        * Таймер: через 30 дней нахождения в корзине файл удаляется автоматически и без предупреждения.

*(Примечание: На главной странице или в списках файлов любого типа файл можно переименовать или удалить с устройства: либо сначала добавив в корзину, либо сразу безвозвратно).*

### 4.2. Вкладка «Читалка» (Интерфейс чтения)
Клик по любому файлу открывает его на этом экране.
*   **Верхний бар (AppBar):**
    *   **Левый верхний угол:** Кнопка «Оглавление». Приложение автоматически определяет, если книга разбита по главам. Можно быстро перейти к нужной главе. Закладки отображаются здесь же или в меню заметок отдельной вкладкой.
    *   **Правый верхний угол (кнопки идут справа налево):**
        *   Кнопка «Настройки» (значок шестерёнки):
            *   Размер шрифта (8пт, 9пт, 10пт, 11пт, 12пт, 14пт, 16пт, 18пт).
            *   Цвет фона (Темный, Белый (по умолчанию), Сепия).
            *   Шрифт (Times New Roman, Rubik, Montserrat, Open Sans, Arial, Calibri и другие).
            *   Сохранение позиции чтения (запоминает абзац, на котором остановился пользователь).
            *   Текст по страницам (переключатель). Если включено — главы загружаются по страницам (одна глава = одна страница). Если выключено — следующая глава подгружается только когда пользователь почти доходит до конца текущей.
            *   Кодировка: Автоопределение, UTF-8, Windows-1251.
        *   Кнопка «Заметки» (значок блокнота с ручкой, слева от настроек). Показывает список заметок пользователя конкретно для открытого файла.
        *   Кнопка «Поиск» (значок лупы, слева от блокнота). Поиск слова в файле (по умолчанию без учёта регистра, включая подстроки). В строке ввода есть стрелки вверх/вниз для быстрого перехода к найденным результатам.
        *   Кнопка быстрого добавления «Закладки» (значок флажка/ленточки, слева от прочих значков).
*   **Рабочая область (Большая, адаптируемая под размер экрана):**
    *   При выделении фрагмента текста всплывает меню: «Копировать», «Добавить в заметку», «Выделить всё», «Копировать всё».
    *   При нажатии «Добавить в заметку» открывается модальное окно: поля "Название заметки" и "Текст заметки", кнопки "Сохранить" и "Отмена". Текст в поле заносится автоматически из выделенного.
*   **Верхний колонтитул (над текстом):** Тонкая, ненавязчивая полоса прогресса и счетчик страниц (напр. 15 / 340). Нажатие на полосу позволяет быстро перемещаться по книге.

### 4.3. Вкладка «Недавнее»
Список из 10 последних открытых файлов. Возможность сортировки по типу файла. Нажатием на любой файл открывается читалка с эти файлов внутри.

## 5. Глобальные элементы интерфейса
*   **Система уведомлений:** В правом верхнем углу приложения (слева от значка настроек) находится иконка колокольчика. Открывает страницу с уведомлениями об обновлениях программы или прочими уведомлениями от разработчиков (запросы к GitHub API происходят в фоне при наличии интернета, данные не передаются).
*   **Экран «Настройки» (Иконка в правом верхнем углу приложения):**
    *   *Основные:* «Не выключать экран телефона» (плавный тумблер), «Тема приложения» (Светлая, Темная (по умолчанию), Сепия), «Языковые параметры» (Русский - по умолчанию, Английский, Китайский), «Автосохранение при редактировании файла» (плавный тумблер, каждые 15 сек), «Автосохранение при чтении» (плавный тумблер, каждые 10 сек — сохраняется абзац и позиция пользователя в файле), «Разрешить отправку отчетов об ошибках» (плавный тумблер).
    *   *Справка:* Условия использования, Политика конфиденциальности (открывают правовые документы внутри самого приложения).
    *   *Обратная связь:* Открывает системный почтовый клиент пользователя (Gmail, Яндекс Почта, Apple Mail — то, что стоит по умолчанию). Предзаполненные поля: "Кому: kochetkov_help@mail.ru", "Тема: Отзыв о приложении EmeraldBook", "Тело письма: пустое место для текста пользователя" + внизу автоматически прикреплена версия ОС и приложения. Прикрепление файлов (до 15 Мб) делается силами самого почтового клиента.
    *   *Информация о программе:* Версия приложения, символ Copyright о защищённых правах.

## 6. Логика первого запуска (Onboarding)
1.  **Модальное окно приветствия (появляется на главной странице):**
    *   Текст: *"Приветствую в приложении EmeraldReader! Оно полностью бесплатное, без рекламы и даже не крадёт ваши данные! :D Однако убедительно просим ознакомиться со страницей "Инфо", чтобы поддержать разработчиков вниманием :) Приятного чтения!"*
    *   Флажок: *"Больше не показывать приветственное окно"*. Если галочка установлена — окно больше не показывается. В ином случае окно будет всплывать при **каждом** открытии приложения.
2.  **Запрос прав:**
    *   Системный запрос на выбор директории для чтения (SAF / Files App).
    *   Шуточный запрос (кастомное окно): *"Мы очень рады, что вы установили нашу offline-читалку! Разрешите нам доставить вам удовольствие от её использования!"* (Кнопка "Разрешаю!").
